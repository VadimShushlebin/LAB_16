## 🔧 Реализованные функции

### 1.double f(double x)
- Назначение: Вычисление значения функции f(x) = x³ - 4x² + 2
- Параметры:
  - x - аргумент функции
- Возвращает: значение функции в точке x

### 2.double* full_elements(double* ptr_array, int n)
- Назначение: Заполнение массива значениями функции f(x) с x=0.0, шаг 0.5
- Параметры:
  - ptr_array - указатель на массив
  - n - размер массива
- Возвращает: указатель на заполненный массив

### 3.int find(int* arr, int size, int type)
- Назначение: Поиск среднего индекса между элементами разных типов
- Параметры:
  - arr - указатель на массив целых чисел
  - size - размер массива
  - type - тип элементов
- Возвращает: индекс между найденными элементами или -1 если не найдено

### 4.double* full_elements_task2(double* ptr_array, int n)
- Назначение: Заполнение массива фиксированными значениями
- Параметры:
  - ptr_array - указатель на массив
  - n - размер массива
- Возвращает: указатель на заполненный массив

### 5.int put_elements(double* ptr_array, int n)
- Назначение: Печать элементов массива
- Параметры:
  - ptr_array - указатель на массив
  - n - размер массива
- Возвращает: количество выведенных элементов

### 6.double* calc_elements(double* ptr_array, int n)
- Назначение: Преобразование элементов массива (изменение знака)
- Параметры:
  - ptr_array - указатель на массив
  - n - размер массива
- Возвращает: указатель на преобразованный массив

### 7.double sum_elements(double* ptr_array, int begin, int end)
- Назначение: Вычисление суммы элементов массива от индекса begin до end включительно
- Параметры:
  -ptr_array - указатель на массив
  - begin - начальный индекс
  - end - конечный индекс
- Возвращает: сумму элементов в заданном диапазоне

### 8.int find_element(double* ptr_array, int n, double element)
- Назначение: Поиск элемента равного заданному значению в массиве
- Параметры:
  - ptr_array - указатель на массив
  - n - размер массива
  - element - искомый элемент
- Возвращает: индекс найденного элемента или -1 если элемент не найден

### 9.int find_min(double* ptr_array, int n, int k)
- Назначение: Поиск порядкового номера минимального значения элементов, кратных k
- Параметры:
  - ptr_array - указатель на массив
  - n - размер массива
  - k - число, кратность которому проверяется
- Возвращает: индекс минимального кратного элемента или -1 если таких элементов нет

### 10.int delete_k(double* ptr_arr, int size, int k)
- Назначение: Удаление каждого k-го элемента из массива
- Параметры:
  - ptr_arr - указатель на массив
  - size - размер массива
  - k - номер удаляемого элемента
- Возвращает: новый размер массива после удаления

### 11.double* insert_after_k(double* ptr_arr, int* size, int k)
- Назначение: Вставка значения -999 после каждого k-го элемента
- Параметры:
  - ptr_arr - указатель на массив
  - size - указатель на размер массива (будет изменен)
  - k - номер элемента после которого выполняется вставка
- Возвращает: указатель на новый массив
