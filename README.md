## 🔧 Реализованные функции

# 1.double f(double x)
- Назначение: Вычисление значения функции f(x) = x³ - 4x² + 2
- Параметры:
  - x - аргумент функции
- Возвращает: значение функции в точке x

# 2.double* full_elements(double* ptr_array, int n)
- Назначение: Заполнение массива значениями функции f(x) с x=0.0, шаг 0.5
- Параметры:
  - ptr_array - указатель на массив
  - n - размер массива
- Возвращает: указатель на заполненный массив

# 3.double* full_elements_task2(double* ptr_array, int n)
- Назначение: Заполнение массива фиксированными значениями
- Параметры:
  - ptr_array - указатель на массив
  - n - размер массива
- Возвращает: указатель на заполненный массив

# 4.int put_elements(double* ptr_array, int n)
- Назначение: Печать элементов массива
- Параметры:
  - ptr_array - указатель на массив
  - n - размер массива
- Возвращает: количество выведенных элементов

# 4.int put_elements(double* ptr_array, int n)
- Назначение: Печать элементов массива
- Параметры:
  - ptr_array - указатель на массив
  - n - размер массива
- Возвращает: количество выведенных элементов
  
# 5.double* calc_elements(double* ptr_array, int n)
- Назначение: Преобразование элементов массива (изменение знака)
- Параметры:
  - ptr_array - указатель на массив
  - n - размер массива
- Возвращает: указатель на преобразованный массив

# 6.double sum_elements(double* ptr_array, int begin, int end)
- Назначение: Вычисление суммы элементов массива от индекса begin до end включительно
- Параметры:
  -ptr_array - указатель на массив
  - begin - начальный индекс
  - end - конечный индекс
- Возвращает: сумму элементов в заданном диапазоне

# 7.int find_element(double* ptr_array, int n, double element)
- Назначение: Поиск элемента равного заданному значению в массиве
- Параметры:
  - ptr_array - указатель на массив
  - n - размер массива
  - element - искомый элемент
- Возвращает: индекс найденного элемента или -1 если элемент не найден
